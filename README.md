# 📊 Sales Dashboard (Tableau)

An interactive and comprehensive **Sales Dashboard** built using **Tableau Public** to analyze retail performance, customer demographics, mall-wise sales distributions, and payment methods.

---

## 🚀 Overview
This project provides deep visibility into key business performance indicators (KPIs)[cite: 1], enabling stakeholders to monitor overall revenue, order volumes, and customer buying preferences across different shopping malls and categories.

---

## 📈 Key Performance Indicators (KPIs)
* **Total Sales:** 251,505,794[cite: 1]
* **Total Quantity:** 298,712[cite: 1]
* **Average Order Value (AOV):** 2,529[cite: 1]
* **Total Invoices:** 99,457[cite: 1]

---

## 📊 Dashboard Visualizations & Sections
The dashboard layout includes the following core components[cite: 1]:
1. **Sales by Category:** Treemap breaking down sales distribution across various product categories[cite: 1].
2. **Sales by Gender:** Pie chart analyzing purchasing trends and behavior categorized by customer gender[cite: 1].
3. **Sales by Payment Mode:** Breakdown of preferred payment methods (e.g., Cash, Credit Card) used by customers[cite: 1].
4. **Sales by Mall:** Horizontal bar chart comparing revenue performance across multiple shopping malls[cite: 1].
5. **Sales by Date (Invoice Month):** Trend line analysis tracking sales fluctuations and seasonality over time[cite: 1].
